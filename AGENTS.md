# Agent instructions

- To set Meridian up for a new person, follow [docs/AGENT_SETUP.md](docs/AGENT_SETUP.md).
- To change the code, read [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md); run `python -m pytest -q` before committing.
- Never commit `data/`, exports, or personal rules; never enter a user's credentials.
- Work on a branch of your fork and open a pull request; `main` is protected.
